"# Image Assets Placeholder Guide

Please place your original photos into the matching subdirectories below:

- `public/images/hero/` -> Homepage hero background image (e.g. `hero-bg.jpg`)
- `public/images/charkha/` -> Handloom and Charkha spinning photos (e.g. `charkha-artisans.jpg`)
- `public/images/programs/` -> Photos for stitching, digital literacy, biogas (e.g. `biogas.jpg`, `stitching.jpg`)
- `public/images/team/` -> Founder Mr. Mahaveer Upadhyay and leadership photos (e.g. `mahaveer-upadhyay.jpg`)
- `public/images/logo/` -> Official logo file (e.g. `logo.png`)

All image components in the code use smooth blur-up fallbacks so the site looks stunning even before photos are added!
